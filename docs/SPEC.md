## 2. 物理メモリの配置（QEMU `virt`）

以下は QEMU `virt` の一般に知られた配置である。
**M0 で `-machine dumpdtb=` によって実物の DTB と照らし合わせ、確認した旨をここに書く。**
M2 以降は、DTB から読んだ値を正とする。

| アドレス | 内容 | 使い始め |
| --- | --- | --- |
| `0x0010_0000` | test デバイス（QEMU の終了に使える） | M0（候補） |
| `0x0200_0000` | CLINT（タイマー、ソフトウェア割り込み） | 直接は触らない予定（SBI 経由） |
| `0x0c00_0000` | PLIC（外部割り込みコントローラ） | M6 |
| `0x1000_0000` | UART0（16550 互換） | M0 または M6 |
| `0x1000_1000` 〜 | virtio-mmio デバイス | M7 以降 |
| `0x8000_0000` | RAM の先頭。OpenSBI が置かれる | ― |
| `0x8020_0000` | カーネルの読み込み先・開始アドレス | M0 |

RAM の大きさは QEMU の `-m` で決まる（既定は 128 MiB）。

## 3. 起動時の約束（OpenSBI → カーネル）

OpenSBI がカーネルへ制御を渡すときの状態。
M0 で実際に確かめ、違いがあれば書き換える。

| 項目 | 状態 |
| --- | --- |
| 開始アドレス | `0x8020_0000`（`pc`） |
| 特権モード | S モード |
| `a0` | 起動した hart の ID |
| `a1` | DTB の物理アドレス |
| `satp` | 0（ページングは無効） |
| 割り込み | 無効 |
| スタック | 未設定。カーネルが自分で用意する |
| `.bss` | 0 クリアされていない。カーネルが自分で埋める |
